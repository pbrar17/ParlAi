## Overview

ParlAi is a cutting-edge developer tool designed to streamline the creation of interactive web applications leveraging generative AI technologies.

**Why ParlAi?**

This project serves as a robust foundation for building dynamic user interfaces. The core features include:

- **🔗 Module Resolution:** Simplifies imports and enhances code organization with path aliases.
- **⚛️ Next.js and React Integration:** Provides a solid framework for developing interactive web applications.
- **🔒 Dependency Management:** Ensures consistent installations across environments with `package-lock.json`.
- **📊 Dynamic User Interfaces:** Facilitates real-time data fetching and user interaction for sports betting.
- **🎨 Responsive Design:** Adapts to user preferences for light and dark modes, enhancing accessibility.
- **⚙️ Error Handling:** Improves user experience by managing data retrieval processes effectively.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** JavaScript
- **Package Manager:** Npm

### Installation

Build ParlAi from the source and intsall dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/pbrar17/ParlAi
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd ParlAi
    ```

3. **Install the dependencies:**

**Using [npm](https://www.npmjs.com/):**

```sh
❯ npm install
```

### Usage

Run the project with:

**Using [npm](https://www.npmjs.com/):**

```sh
npm start
```

### Testing

Parlai uses the {__test_framework__} test framework. Run the test suite with:

**Using [npm](https://www.npmjs.com/):**

```sh
npm test
```
